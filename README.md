# 🐝 Monitoreo Apícola - Constru_Monitoreo

Este proyecto Flutter permite monitorear colmenas apícolas en tiempo real mediante sensores IoT. Forma parte del sistema de vigilancia y mantenimiento preventivo desarrollado para mejorar la calidad en la producción de miel y conservar el ecosistema de abejas.

## 📱 Características principales

- Visualización del estado de las colmenas (ubicación, estado, temperatura, humedad, etc.)
- Registro de mantenimientos y observaciones
- Generación de reportes integrales
- Conexión con Firebase para almacenamiento en la nube
- Interfaz moderna y responsiva
